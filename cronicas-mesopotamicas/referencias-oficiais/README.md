# Referências oficiais — Crônicas Mesopotâmicas

Este diretório é a **fonte canônica de identidade visual e conteúdo de referência** para qualquer Work/agente que crie, revise ou publique páginas relacionadas a **Crônicas Mesopotâmicas — Deuses Famintos**, de **Ugo Leão**.

## Regra obrigatória de consulta

Antes de alterar layout, identidade visual, capa, logotipo, copy relacionada ao bônus ou arquivos de entrega, consulte primeiro este diretório. Não substitua estes arquivos por versões encontradas fora daqui sem orientação explícita do editor.

## Arquivos

- `capa-aprovada-cronicas-mesopotamicas.png` — capa aprovada para referência visual. Não reconstruir, redesenhar, recolorir ou reiluminar com IA.
- `logo-fantasticos-original.jpg` — arquivo-fonte do selo/logotipo Fantásticos enviado pelo editor. Não reconstruir nem redesenhar. Se for necessário remover o fundo para uso web, fazer apenas remoção técnica de fundo/transparência, preservando o desenho original.
- `arte-original-sem-tipografia.png` — arte-base original fornecida antes da aplicação da tipografia. Usar apenas como referência e nunca substituir a capa aprovada sem autorização.
- `conto-a-epifania-do-escriba-FONTE.md` — ponteiro canônico para o documento do conto no Google Drive. O texto integral não fica no repositório público para evitar vazamento da obra.
- `manifesto-referencias.json` — status e fontes dos ativos.

## Atualização do conto

Quando Ugo Leão enviar a versão revisada, atualizar o documento canônico no Drive (ou o link em `conto-a-epifania-do-escriba-FONTE.md`, se mudar) e atualizar o `manifesto-referencias.json` para marcar o conto como aprovado apenas depois da conferência editorial.

Enquanto o status do conto for `provisorio_nao_publicar`, não gerar nem disponibilizar PDF/EPUB ao público.
